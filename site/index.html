01 / 连续播放

网易云切歌有停顿，可以怎样改善？

现场专辑、古典乐和连续混音常把一段声音分成多首曲目。NCM Gapless 提前下载并解码下一首，将它安排在当前曲目的结尾播放，减少等待换曲后才加载造成的间隔。

声音由客户端中的 Web Audio 引擎输出，官方界面继续负责选曲和队列。音源必须来自当前账号经官方流程取得的授权播放信息。

连续效果取决于音源本身是否连续，以及下一首能否及时准备好。补丁不会删除原有静音，也不提供会员或版权限制绕过。

03 / 安装使用

Windows / Mac 如何启用无缝播放？

下载源码 ZIP 后完整解压，保留目录结构。运行前先完全退出网易云音乐。

Windows

  1. 双击 Start-NcmGapless.cmd 启动并启用补丁。
  2. 在网易云中重新选择一首歌曲开始播放。
  3. 双击 Get-NcmGaplessStatus.cmd 查看状态。

无需安装 Python、Node.js，也无需管理员权限。

macOS

  1. 安装 Python 3，双击 Start-NcmGapless.command。
  2. 首次运行会在解压目录创建 .venv，联网安装依赖。
  3. 重新选曲，用 Get-NcmGaplessStatus.command 查看状态。

依赖只安装到项目目录，后续启动复用该环境。

当前下载入口为仓库源码 ZIP。非标准安装路径和启动错误的处理方式见下方使用说明。

04 / 常见问题

使用前，你可能还想知道

无缝播放和交叉淡化有什么区别？

交叉淡化会让前后两首的声音重叠并渐变。NCM Gapless 按音频时钟接续曲目，不混合两首声音，不删除歌曲自身的静音，适合尝试连续专辑播放。

为什么第一首需要等待，切歌仍然可能停顿？

每首歌都需要完整下载并解码。网络速度、音轨大小和内存预算会影响准备时间。下一首未及时准备好时，无法保证连续衔接；曲目本身包含的静音也会保留。

支持 FLAC、MP3 和本地缓存吗？

支持授权播放信息中的 MP3、FLAC、WAV 和部分 AAC/M4A。无法可靠确定时长的音源、加密本地缓存、试听和权限受限内容会继续走官方播放路径。

怎样关闭补丁，会修改客户端文件吗？

Windows 运行 Stop-NcmGapless.cmd，Mac 运行 Stop-NcmGapless.command，即可停用并恢复官方播放。补丁只驻留内存，不修改安装文件。重启网易云会清除补丁，下次需重新启用。

支持所有网易云版本、蓝牙和官方音效吗？

仅适配上表中的客户端版本。蓝牙、空间音频、独占设备、系统媒体控制和复杂队列操作仍需验证，表现可能与官方播放器不同。当前为实验版本，请先确认自己的使用场景。

遇到问题应该提供什么信息？

通过 GitHub Issues 反馈，附上系统、客户端与补丁版本、重现步骤和脱敏状态。不要上传 Cookie、令牌、签名音源地址或歌曲文件。
