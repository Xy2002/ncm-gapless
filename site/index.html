01 / 连续播放

网易云切歌有停顿，可以怎样改善？

现场专辑、古典乐和连续混音常把一段声音分成多首曲目。NCM Gapless 提前下载并解码下一首，将它安排在当前曲目的结尾播放，减少等待换曲后才加载造成的间隔。

声音由客户端中的 Web Audio 引擎输出，官方界面继续负责选曲和队列。音源必须来自当前账号经官方流程取得的授权播放信息。

连续效果取决于音源本身是否连续，以及下一首能否及时准备好。补丁不会删除原有静音，也不提供会员或版权限制绕过。

03 / 安装使用

Windows / Mac 如何启用无缝播放？

Windows 自动维护需要下载含已编译模块的安装包；macOS 或开发者可使用源码 ZIP。下载后完整解压，保留目录结构。

Windows

  1. 下载 Windows maintenance 包，双击 Install-NcmGaplessMaintenance.cmd，允许一次管理员安装。
  2. 客户端关闭后由系统完成安装或修复；以后从原图标打开即可自动加载。
  3. 在网易云中重新选择一首歌曲开始播放。
  4. 双击 Get-NcmGaplessStatus.cmd 查看状态。

无需 Python 或 Node.js。下载 Windows 自动维护包 ↗；只启用本次运行时，可使用无需管理员权限的 Start-NcmGapless.cmd。

macOS

  1. 安装 Python 3，双击 Start-NcmGapless.command 进入初始化向导。
  2. 按向导完成首次系统确认，脚本自动准备依赖和快捷指令，并在普通启动自检通过后显示“配置完成”。
  3. 重新选曲，用 Get-NcmGaplessStatus.command 查看状态。
  4. macOS 27 配置后可直接打开原客户端，退出重开也会自动启用，直到执行停止脚本。

辅助脚本按需执行后退出，保留原厂签名。普通启动可能自动重开一次客户端。

Windows 自动维护会在客户端关闭后修复缺失模块并获取签名更新。非标准安装路径和启动错误的处理方式见下方使用说明。

04 / 常见问题

使用前，你可能还想知道

无缝播放和交叉淡化有什么区别？

交叉淡化会让前后两首的声音重叠并渐变。NCM Gapless 按音频时钟接续曲目，不混合两首声音，不删除歌曲自身的静音，适合尝试连续专辑播放。

为什么第一首需要等待，切歌仍然可能停顿？

每首歌都需要完整下载并解码。网络速度、音轨大小和内存预算会影响准备时间。下一首未及时准备好时，无法保证连续衔接；曲目本身包含的静音也会保留。

支持 FLAC、MP3 和本地缓存吗？

支持授权播放信息中的 MP3、FLAC、WAV 和部分 AAC/M4A。无法可靠确定时长的音源、加密本地缓存、试听和权限受限内容会继续走官方播放路径。

怎样关闭补丁，会修改客户端文件吗？

Windows 运行 Stop-NcmGapless.cmd，Mac 运行 Stop-NcmGapless.command，即可停用并恢复官方播放。Windows 自动维护会新增本项目模块和系统任务，保留网易云原厂文件；停止脚本撤销当前账号的自动加载，物理卸载会先撤销维护任务。macOS 27 完成一次性快捷指令配置后会自动加载，直到执行停止脚本。Mac 辅助脚本按需运行后退出，保留原厂签名。

支持所有网易云版本、蓝牙和官方音效吗？

上表记录实测版本，Windows 兼容探测不代表所有未来版本均已适配。未知内核需要等待新的适配补丁。蓝牙、空间音频、独占设备、系统媒体控制和复杂队列操作仍需验证，表现可能与官方播放器不同。当前为实验版本，请先确认自己的使用场景。

遇到问题应该提供什么信息？

通过 GitHub Issues 反馈，附上系统、客户端与补丁版本、重现步骤和脱敏状态。不要上传 Cookie、令牌、签名音源地址或歌曲文件。
