# 路线图

更新时间：2026-10-26。当前实现：`0.3.1-experimental`；Windows 真实输出基线为 `0.2.1-experimental`，macOS 播放接入基线为 `0.3.0-experimental`。

项目目标是在官方账号、队列和权限流程内改善连续专辑播放。平台支持以真实运行结果为准；下面尚未勾选的项目均未完成。

## 已有基线

- [x] 接入网易云 3.1.42.205594 x64 的真实播放链路。
- [x] 当前与下一首共用 AudioContext，提前解码并预排。
- [x] 暂停、恢复、定位、状态反馈与停用恢复。
- [x] 修复相同倍速重复设置导致第二首重启。
- [x] Dawn FM → Gasoline 自然换歌的本机输出回录验证。
- [x] Windows PowerShell 5.1 启用、状态检查及冷启动验证。
- [x] 加载期间的暂停 / 恢复和停用恢复回归修复。
- [x] 拒绝将粗粒度 AAC 编辑时长的整数转换误判为精确终点。

## P0：先把当前实现做稳

### AAC 时长兼容

- [ ] 为 `AAC_INTENTIONAL_EDIT_UNSUPPORTED` 的布局建立不含真实音频的生成样本。
- [ ] 区分可由元数据确定的有效范围、粗粒度编辑时长和无法恢复的尾部填充。
- [ ] 只有证据足够时扩展时长适配；无法确定时保留回退及明确状态。
- [ ] 扩充独立解码参考、回归用例与真实衔接回录。

验收：原失败布局有可重复的前后对照，既验证尾部长度，也验证下一首开头；不以跳静音或交叉淡化掩盖问题。

### 播放与状态稳定性

- [ ] 连续多次自然换歌，记录每个衔接的真实输出。
- [ ] 覆盖随机、单曲循环、手动前后切歌、队列增删与重排。
- [ ] 覆盖加载中暂停、反复定位、真实倍速变化和切换音质。
- [ ] 覆盖网络中断、链接过期、内存预算、睡眠唤醒和设备切换。
- [ ] 改进已接管、预加载失败、等待交接和原生回退的诊断信息。

验收：取消任务不继续发声，官方状态与实际声音一致；错误能恢复，报告不含账号和音源数据。

## P1：建立平台适配边界

### Windows 验证矩阵

- [ ] Windows 10 与更多 Windows 11 构建的 x64 实机测试。
- [ ] 按网易云版本分别记录适配与拒绝启用的行为。
- [ ] x86 / ARM64 根据可获得的设备和客户端逐项验证。
- [ ] 单独评估官方音效、空间音频、系统媒体控制和蓝牙。

验收：每个被标为支持的组合都有安装、启用、停用、冷启动、控制及自然换歌输出记录。

### macOS 可行性研究

- [x] 在真实 Mac 上记录网易云 `3.1.12.3444`、通用应用包与 Chromium `116.0.5845.190`，运行环境为 Apple Silicon；客户端 UA 声称的 Chrome 120 不作为内核版本。
- [x] 核实官方 SDK、旧界面桥、队列、授权 FLAC 音源与播放状态接口。
- [x] 使用应用启动参数开放回环 CDP，不修改应用包或签名；实测端口冲突后选择其他端口。
- [x] 复用 Web Audio 核心，完成 8 项连续性、16 项编解码与 7 项引擎 / 事件检查。
- [ ] 完成 macOS 应用输出设备回录并与解码参考对照。
- [x] 将 Mac SDK / 旧界面桥和启动器独立适配，复用 AAC、音频核心和调度引擎。

验收：官方授权音源能到达可测量的 PCM 输出，且存在可撤销的启用 / 停用路径。Windows 上的成功不作为 macOS 的验证结果。
